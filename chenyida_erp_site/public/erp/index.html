现场执行顺序

  1. 采购在“供应商导入”上传 CSV、XLS 或 XLSX 文件。
  2. 系统自动匹配内部物料并分流。

  4. 新物料走建档，生成晨亿达内部物料编码。
  5. BOM、采购、库存、生产只使用内部物料编码。

BOM 管理

把内部标准物料挂到产品版本，后续采购齐套、生产工单都从这里展开。

BOM属于产品版本；具体项目在计划交接时关联。
  1. 先保存草稿，再添加并校验行项目。
  2. 草稿创建后，发布按钮会出现在下方 BOM 列表；发布前由服务端再次校验全部行项目。
  3. 发布后内容不可原地修改，需要新建修订版本。
  4. 发布后才可用于计划交接；Planning Handoff 只接受已发布的 Product Version 与 BOM Version。
