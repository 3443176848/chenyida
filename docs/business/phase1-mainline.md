# 第一阶段部门业务主线

状态：已确认；适用起点 `SELFHOST-PHASE4-TASK01`。

第一阶段按下列责任链逐段建设，不允许前一段提交自动生成后一段业务单据：

`客户 → 市场部门 → 项目部门 → 计划部门 → 采购部门 → 仓库部门 → 财务部门`

本阶段后期再接生产、品质、完工和发货。当前 TASK01 只交付客户需求由市场整理后交给项目部门、项目部门接收或退回、市场修订重提并最终接收的闭环。

## TASK01 责任边界

- 市场部门复用 `sales` 角色：创建本人项目需求草稿、形成不可变修订版本、提交/重新提交、查看本人负责项目。
- 项目部门复用 `engineering` 角色：读取待接收队列和安全资料元数据、接收或填写原因退回、查看本人已接收项目。
- 项目使用稳定内部 ID 和 `PRJ-########` 独立编号；客户名称、客户料号、销售订单号均不是主键。
- 接收、退回、重新提交形成不可变交接事件，并与请求编号、系统审计和持久幂等记录在同一事务提交。
- 技术资料只引用既有受控文件 ID；项目 API 不返回存储名、相对/绝对路径或文件正文。

## 本任务不产生的业务事实

TASK01 不自动创建或启动 Product、Product Version、BOM、销售订单、计划、物料需求、采购申请、询报价、采购订单、工单、检验、库存过账、财务成本或真实数据迁移。生产、品质等现有模块继续保留，但不是 TASK01 主线。

## 后续路线（仅记录，不启动）

- TASK02：项目部 → 计划部，产品/BOM/规格交接。
- TASK03：计划物料需求与采购申请。
- TASK04：供应商询价、报价和比价。
- TASK05：采购 → 仓库 → 财务交接。
- 后续阶段：生产、品质、完工和发货接入。
